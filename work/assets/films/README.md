# Four showcase films

Four independently rendered Blender concept films: establish a personal workspace, exchange the engine while retaining identity/state, carry a complete asset beyond its workspace, and continue remembered history.

Each theme variant is 1280×800, 10 seconds, 600 actual rendered frames at 60 fps, H.264 without audio. The `start` WebP is the loading poster; `end` is the result poster for reduced motion. Existing outside headings carry the bilingual meaning.

Provenance: independently copied existing website Pathfinder GLB, SHA-256 36507991df9c0ca9503adf6c953e44233fe9b7525a2fba842b4e6e736aa7bfde. No desktop source or runtime resource dependency.

Editable Blender projects, scene generator, original PNG masters and verification evidence are preserved at `D:/preacherman/output/blender/web-four-films-20260916/`. `delivery.json` records final hashes and checks.

Only the visible film plays. Inactive/hidden/modal-covered films pause. Changing appearance preserves the story clock; completion holds the final frame. The small control allows explicit Pause/Play/Replay. Reduced-motion users see the result poster unless they explicitly choose Play.

The local dev server supports video byte ranges. Published files remain explicit in `scripts/frontend-assets.mjs`. Videos are copied into both build destinations; this delivery does not publish to a domain.
