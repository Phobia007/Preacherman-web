# Archived frontend source fragment

This directory is retained as historical material only. It is not the current
Preacherman frontend source and must not be used to regenerate the latest page.

The directory predates `work/Preacherman-Standalone.html`, contains an older
HTML/CSS/JavaScript snapshot, and is missing assets referenced by that snapshot.
Rebuilding from it would lose newer visual, content, interaction, and local-auth
changes.

Current rules:

- Canonical HTML: `work/Preacherman-Standalone.html`
- Authentication entry: `work/preacherman-auth.js`
- Development: `npm run dev`
- Build: `npm run build`
- Generated output: `dist/` (never edit manually)

See `docs/frontend-source-of-truth.md` before any future source migration.
